# Kate-Dale-Archaeology-Honours-Thesis
This Excel document contains multiple worksheets that contain the Dataset Schema definitions and the Dataset as well as additional worksheets that contain pivot tables and charts created to analysis specific aspects of the dataset.

Dataset Schema Worksheet: Contains the defintions for each of the fields within the dataset 

Definitions Worksheet: Contains the definitions for the historical themes, place type and place categories, coordinate precision ranking and time periods assigned to each dataset entry

Dataset Worksheet: Contains the 306 place name references gathered during the literature review

Period Worksheet: Contains pivot tables and charts created to analyse this aspect of the dataset

Historical Theme Worksheet: Contains pivot tables and charts created to analyse this aspect of the dataset

Place Cateogory Data Worksheet: Contains pivot tables and charts created to analyse this aspect of the dataset

Place Type Data Worksheet: Contains pivot tables and charts created to analyse this aspect of the dataset

Place Type by Place Category Worksheet: Contains pivot tables and charts created to analyse these aspects of the dataset

Place Name Count: Contains a consolidated list of each place name and the number of times there are recorded in the dataset

Place Name by Coordinate Precision Worksheet: Contains a consolidated list of each place name and their coordinate precision ranking

Place Name by Place Category Worksheet: Contains a consolidated list of each place name and their assigned place categories

Place Name by Historical Theme Worksheet: Contains a consolidated list of each place name and their assigned historical themes

APB Annual Reports Worksheet: Contains data extracted from the Aborigines Protection Board Annual Reports from 1882-1898 (the Annual Reports for 1899 and 1900 were not located)
